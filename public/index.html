Asset Management.

CHARMS is a full-stack Custodian & Resource Asset Management System built for a public-sector office. It tracks Property, Plant & Equipment and semi-expendable items across their complete lifecycle—from acquisition and issuance to transfer, return, and disposal.

The platform combines policy-aware classification, controlled document generation, employee records, and traceable activity history in one audit-ready workflow.

  • Automatic PPE and semi-expendable classification with cost-threshold validation
  • Auto-generated PAR and ICS issuance documents

  • Alphabetized employee roster and full activity-log tracking
  • Acquisition, issuance, transfer, return, and disposal lifecycle coverage

PROJECT NOTES / P-006

Central Mind
OS.

Central Mind OS is a self-contained personal life-management application built entirely as a single HTML file — no backend, no build step, running fully offline with all data persisted locally in the browser. It brings together a radial mind-map hub for high-level life categories, full task/goal/note/project CRUD, a calendar with due-date tracking, and an "Accomplished" tracker that automatically aggregates completed work into a searchable list, calendar view, and weekly metrics chart.

Each project has its own dedicated page with a work-log composer and a scoped calendar showing exactly which days had logged activity, paginated for readability. The interface features a dark neon glassmorphism design system with an animated Three.js starfield background, a live-rotating 3D icosahedron hub icon, animated SVG "energy pathway" connectors between mind-map nodes, and pointer-following 3D tilt on interactive cards — all respecting prefers-reduced-motion for accessibility.

To support use across multiple devices, the app includes an optional Cloud Sync layer built on Firebase Firestore with simple PIN-based access (no account or login required), using debounced writes and a live listener to keep every connected device in sync in real time.

  • Radial mind-map hub with animated SVG connectors between nodes
  • Full task, goal, note, and project CRUD with a due-date calendar
  • Auto-aggregating "Accomplished" tracker — list, calendar, and weekly metrics chart
  • Per-project work-log composer with a scoped, paginated activity calendar
  • Animated Three.js starfield and rotating 3D icosahedron hub icon
  • Optional PIN-based Firebase Firestore cloud sync across devices, no account required
  • Vanilla JavaScript
  • HTML5
  • CSS3
  • Three.js
  • Firebase Firestore
  • localStorage
